All-in-One runs the Server and Agent on the same Linux host for evaluation and testing.

Follow [Getting started](/en/docs/getting-started/) to prepare the host, install v1.7.0 kcctl, download the complete package, deploy the platform, and create a test cluster.

For production, plan separate Server and workload nodes and see [high availability](/en/docs/deployment-docs/ha-deploy/).
