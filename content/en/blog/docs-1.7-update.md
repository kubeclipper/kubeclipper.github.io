We refreshed the KubeClipper v1.7.0 documentation so new and existing users can follow tasks from installation to troubleshooting. This is a **documentation update**. The v1.7.0 software was released on September 8, 2026; see the [1.7 release notes](/en/docs/overview/release-1.7/) for shipped capabilities and component versions.

- [Getting started](/en/docs/getting-started/) covers host preparation, platform deployment, a test cluster, and completion checks.
- [Upgrading](/en/docs/deployment-docs/upgrade/) lists pre-upgrade checks and operational boundaries.
- [Operations and logs](/en/docs/tutorials/operations/) explains asynchronous task status, logs, retry, and cancellation.
- [Platform diagnostics](/en/docs/tutorials/diagnostics/) helps distinguish platform, Agent, resource, and cluster failures.
- The version menu links to archived documentation for 1.1 through 1.6; current documentation covers v1.7.0.

If a step is wrong or a use case is missing, [open a documentation issue](https://github.com/kubeclipper/kubeclipper.github.io/issues/new). Include the page URL, your version, and redacted error details.
