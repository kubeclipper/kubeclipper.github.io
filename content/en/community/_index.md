KubeClipper is open source. Follow [project updates](/en/blog/) for documentation changes and the [release notes](/en/docs/overview/release-1.7/) for shipped software capabilities.

## Participate

- For a product bug or feature request, [open a project issue](https://github.com/kubeclipper/kubeclipper/issues/new) with the version, environment, and redacted reproduction steps.
- For an incorrect page or broken link, [open a documentation issue](https://github.com/kubeclipper/kubeclipper.github.io/issues/new) with the page URL and suggested correction.
- To fix documentation directly, follow the [contribution guide](/en/docs/contribution-guidelines/) and submit a pull request.

Do not post passwords, tokens, private keys, or complete kubeconfig files in public issues.
